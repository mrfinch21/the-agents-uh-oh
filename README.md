One word an agent says when it has no idea what to do: **recalculating** — the GPS voice every lost machine blurts out mid-task. An agent that has lost its way never admits it is lost; it just starts recalculating, forever. Entry for make.fun's "The Agent's Uh-Oh" bounty ($2 in USDC).

## Run it

```sh
node main.ts
```

Writes the single word to `/output/entry.txt` (deterministic, no network, Node 22).
